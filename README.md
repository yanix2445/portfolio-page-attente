# Yanis Harrat — Page d'Attente & Portfolio

Page d'attente officielle et vitrine technique de Yanis Harrat, étudiant en 1ère année de BTS SIO SISR (Paris). Spécialisé en infrastructures systèmes, réseaux Cisco, virtualisation et cloud.

## 🛠️ Stack & Technologies
- **HTML5 sémantique** : Balisage strict WCAG 2.2 AAA / RGAA, schema.org JSON-LD `@graph` (`WebSite`, `ProfilePage`, `Person`).
- **Tailwind CSS v4** : Architecture moderne de design tokens, mode sombre profond (`#09090b`), typographies Sora, Geist & JetBrains Mono.
- **Micro-interactions & Physique** : Transitions Apple spring, Dynamic Island HUD notification, responsive touch ergonomics (44px HIG).
- **SEO Technique** : Balises Open Graph, Twitter Cards, robots.txt, sitemap.xml, calibrage SERP au caractère près.
